# 나이트 베이스볼 3D 업데이트 프롬프트

사용자가 보낸 `나이트 베이스볼 3D.html`을 이 저장소(myongg14/fullcount)의 게임으로 쓰기로 하고(2026-10-31), 그 게임을 더 좋게 만드는 코드 작업용 프롬프트다. 아래 프롬프트를 **순서대로 하나씩** 코드 작업에 붙여 넣는다. 한 단계가 끝날 때마다 iPad에서 열어 확인하고 다음 단계로 넘어간다.

- 매 프롬프트 맨 앞에 **0. 공통 머리말**을 같이 붙인다.
- 한 번에 여러 단계를 붙이지 않는다.
- 버그가 나오면 맨 아래 **버그 수정 프롬프트** 틀을 쓴다.

## 지금 게임 상태 (2026-10-31 확인)

잘 되어 있는 것: 9회 경기(초 타격·말 투구), 도루·번트·추가 진루·태그업, 투구폼 4가지와 투수별 구종, 투구 세기 막대, 견제·고의사구, 다이빙 캐치·홈런 훔치기, 시프트, 바람, 슬로모션 리플레이, 시즌 9경기, 홈런더비, 기록실.

부족한 것:
- **코드가 118KB 한 파일에 빽빽하게** 붙어 있어서, 프롬프트로 고칠 때 실수가 나기 쉽다. → 1단계
- **iPad 성능**: 그리는 해상도 배율이 최대 2.5배이고 부드러운 그림자를 써서, iPad에서 끊길 수 있다(예전 풀카운트도 같은 문제를 1.25배로 줄여 해결했다). → 2단계
- **일시정지, 난이도, 이닝 수, 소리 설정이 없다.** → 2·3단계
- **화면 가운데 핫존 격자**가 투수와 공을 가린다. → 4단계
- **타격은 화면 아무 데나 탭**, 투구는 드래그 후 떼기만 해서 손맛이 얕다. → 5·6단계
- 수비는 다이빙 버튼 하나뿐이다. → 7단계
- 심판 콜이 없다. → 8단계
- 시즌 진행이 새로고침하면 사라진다. → 9단계

| 순서 | 단계 | 분야 |
| --- | --- | --- |
| 1 | 코드 파일 나누기와 읽기 쉽게 정리 | 기술 |
| 2 | iPad 성능과 일시정지 | 기술 |
| 3 | 시작 메뉴 설정: 난이도, 이닝, 낮/밤, 소리 | 화면 |
| 4 | 화면 정리: 핫존, 버튼 배치, 공이 잘 보이게 | 화면 |
| 5 | 타격 손맛: 히트 스톱, 타이밍 미터, 정밀 타격 | 타자 |
| 6 | 투구 손맛: 줄어드는 링 제구 | 투수 |
| 7 | 수비 조작: 캐치 링, 송구 베이스 고르기 | 수비 |
| 8 | 소리: 심판 콜, 타격음·함성 다듬기 | 소리 |
| 9 | 시즌 저장과 팀·선수 이름 편집 | 기록 |

순서 이유: 1번(파일 나누기)을 해야 이후 프롬프트가 정확한 파일만 고칠 수 있다. 2·3번은 iPad에서 편하게 시험하기 위한 기본기, 4~7번은 손맛, 8·9번은 마무리다.

```
나는 개발이 처음인 사람이고, iPad Safari에서 혼자 플레이할 3D 야구 게임 "나이트 베이스볼 3D"를 업그레이드하고 있어.
- 저장소: myongg14/fullcount. 게임은 three.js r128(cdnjs)을 쓰는 웹페이지야. 빌드 도구 없음.
```

## 1. 코드 파일 나누기와 읽기 쉽게 정리

```
index.html 한 파일에 모든 코드가 한 줄에 여러 문장씩 빽빽하게 들어 있어. 앞으로 계속 고쳐 나갈 수 있게 정리해줘.

- 빌드 도구 없이, index.html에서 <script src="js/파일.js"> 로 순서대로 불러오는 방식으로 나눠줘. CSS는 css/style.css로.
- 나누는 기준 예시: core.js(설정값 CFG, 공통 함수), scene.js(렌더러·카메라·조명·하늘), stadium.js(구장·관중·전광판), players.js(선수 모델·애니메이션), audio.js(소리), pitching.js(투구·구종·투수 데이터), batting.js(스윙·타구 판정), fielding.js(수비·송구·다이빙), running.js(주루·도루·태그업), game.js(경기 진행·카운트·이닝), season.js(시즌·홈런더비·기록실), ui.js(화면 표시·버튼), main.js(매 프레임 처리·입력·시작).
- 한 줄에 한 문장, 들여쓰기, 한 글자짜리 변수 이름 중 자주 쓰이는 것(예: st, b, s, PM)은 뜻이 보이는 이름으로 바꾸고, 함수마다 하는 일을 한국어 주석 한 줄로.
- 기능은 하나도 바뀌면 안 돼. 나눈 뒤에도 지금과 똑같이 동작해야 해.
- 각 파일 맨 위에 이 파일이 맡는 일을 한 줄로 적고, README.md에 파일 목록과 역할을 적어줘.
```

확인: 타격·투구·시즌·홈런더비가 전과 똑같이 되는지.

## 2. iPad 성능과 일시정지

```
iPad에서 끊기지 않게 하고, 경기 중에 멈출 수 있게 해줘.

성능:
- 그리는 해상도 배율을 최대 1.25배로(지금 2.5배). scene.js 맨 위 PERF 설정표에 maxPixelRatio로.
- 그림자: 부드러운 그림자(PCFSoft) 대신 가벼운 방식으로, 그림자 지도 크기도 줄이기. 관중·전광판처럼 움직이지 않는 것은 그림자를 받지도 드리우지도 않게.
- 파티클(불꽃) 최대 개수를 300개 이하로.
- 화면 구석에 작게 초당 프레임 수를 보여 주는 기능을 PERF.showFps로 켜고 끌 수 있게(기본 끔).

일시정지:
- 화면 오른쪽 위에 일시정지 버튼(❚❚). 누르면 게임 시간이 멈추고 "이어하기 / 처음으로" 창.
- iPad에서 다른 앱으로 갔다 오면(화면이 숨겨지면) 자동으로 일시정지.
```

확인: 9회 경기 중 끊김이 줄었는지, 일시정지·이어하기가 잘 되는지.

## 3. 시작 메뉴 설정: 난이도, 이닝, 낮/밤, 소리

```
타이틀 화면에서 경기 설정을 고를 수 있게 해줘. 지금 있는 투수 선택, 시즌, 홈런더비 버튼은 그대로 둬.

- 난이도: 루키 / 프로. 루키는 공이 15% 느리게 오고 스윙 판정 시간 폭이 넓음, 컴퓨터 타자도 덜 잘 침. 프로는 지금 그대로.
- 이닝: 3 / 6 / 9 (한 경기 모드에만, 시즌은 9회 고정).
- 시간: 자동(지금처럼 이닝 따라 변함) / 낮 / 저녁 / 밤.
- 소리: 켜기 / 끄기, 음량 막대.
- 고른 설정은 기기에 기억(localStorage, 못 하면 그냥 넘어가기).
- 설정 버튼들은 타이틀 화면에서 한눈에 보이게 2줄 정도로 깔끔하게.
```

확인: 루키에서 공이 느려지는지, 3회를 고르면 3회에 끝나는지, 소리를 끄면 조용한지, 새로고침해도 설정이 남는지.

## 4. 화면 정리: 핫존, 버튼 배치, 공이 잘 보이게

```
타격 화면에서 공이 잘 보이게 정리해줘.

- 화면 가운데 스트라이크존 위의 큰 핫존 색칸이 투수와 공을 가려. 기본은 존 테두리만 얇게 보이고, 핫존 색은 타자 카드(화면 구석) 안의 작은 9칸 그림으로만 보여줘. 설정에서 "존 위에 핫존 표시"를 켜면 지금처럼 보이게(투명도는 지금보다 훨씬 옅게).
- 공이 지나가는 화면 가운데에는 글자 배너가 오래 머물지 않게(1초 뒤 위로 작게).
- 번트·스윙 방식·노림수 버튼은 화면 아래 양옆, 엄지 닿는 곳에.
- 왼쪽 가운데 작은 타자 상자와 오른쪽 위 타자 카드가 겹치는 정보면 하나로 합쳐줘.
```

확인: 공이 투수 손을 떠나서 홈까지 오는 동안 가리는 게 없는지.

## 5. 타격 손맛: 히트 스톱, 타이밍 미터, 정밀 타격

```
타격 손맛을 더 키워줘. 지금 판정 규칙은 기본으로 두고, 보여 주는 것과 선택할 수 있는 방식을 추가해.

- 히트 스톱: 맞힌 순간 화면을 아주 잠깐 멈춤. 정타 0.08초, 보통 0.04초, 빗맞음·파울은 없음.
- 타이밍 미터: 스윙할 때마다 화면 아래에 가로 막대를 잠깐 띄워 완벽(가운데)에서 얼마나 빨랐는지/늦었는지 점으로, "완벽!", "조금 빠름", "늦음" 글자도. 헛스윙 때도.
- 정밀 타격(설정에서 켜기): 화면 아무 데나가 아니라 공이 있는 곳을 탭해야 함. 탭 위치가 공보다 위면 땅볼, 아래면 뜬공이 되기 쉽고, 많이 벗어나면 헛스윙. 대신 정확히 맞히면 타구가 더 셈. 공이 지나간 자리 표시 옆에 내가 탭한 자리를 흰 X로.
- 숫자는 batting.js 맨 위 HIT_FEEL 설정표에.
```

확인: 정타 때 멈추는 느낌이 답답하지 않은지, 정밀 타격을 켜면 위치에 따라 타구가 달라지는지.

## 6. 투구 손맛: 줄어드는 링 제구

```
투구에 타이밍 손맛을 추가해줘. 지금 방식(구종 선택 → 드래그 조준 → 손 떼면 투구, 세기 막대)은 그대로 두고, 제구를 손맛으로 정하게 해.

- 드래그로 조준하는 동안 조준점에 흰 링과, 크게 시작해서 줄어들었다 다시 커지기를 반복하는 노란 링을 보여줘.
- 노란 링이 흰 링과 겹칠 때 손을 떼면 "완벽한 릴리스"로 조준한 곳 거의 그대로, 많이 어긋나면 크게 빗나감(실투는 가운데로 몰리기도).
- 노리는 곳이 존 테두리에 가까울수록 맞는 구간이 좁아지고(흰 링이 주황색), 투수 체력이 낮을수록 링이 빨리 줄어듦. 세기 막대가 셀수록 링도 빨라짐.
- 던진 뒤 "완벽한 릴리스 / 좋은 릴리스 / 실투"를 짧게.
- 숫자는 pitching.js 맨 위 RING_TUNING 설정표에.
```

확인: 링 타이밍에 따라 공이 들어가는 곳이 달라지는지, 테두리를 노리면 더 어려운지.

## 7. 수비 조작: 캐치 링, 송구 베이스 고르기

```
수비할 때 내가 할 일을 늘려줘.

캐치 링:
- 지금 다이빙 캐치 버튼 대신, 아슬아슬한 타구가 오면 공이 떨어질 곳에 흰 링과 줄어드는 노란 링을 띄우고 시간을 0.5배로 느리게. 겹칠 때 링을 탭하면 다이빙(낮은 공)·점프 캐치(담장 근처), 홈런 훔치기도 같은 방식.
- 화면 스와이프로 다이빙하는 기존 방식도 남겨둬.

송구 고르기:
- 땅볼을 내야수가 잡는 순간 주자가 있으면 베이스(1·2·3루·홈) 위에 큰 원 버튼이 뜨고 시간이 느려짐. 탭한 베이스로 송구, 병살을 노리면 2루 → 1루 자동 연결.
- 컴퓨터 주자가 태그업하면 홈/3루 버튼이 떠서 고름.
- 1.2초 안에 안 고르면 지금처럼 자동 처리. 주자가 없으면 버튼 없이 1루 송구.
```

확인: 링이 너무 자주 뜨지 않는지, 고른 베이스로 송구하는지, 안 고르면 자동으로 되는지.

## 8. 소리: 심판 콜, 타격음·함성 다듬기

```
소리를 더 야구장답게 해줘.

- 심판 콜: "스트라이크!", "볼!", "아웃!", "세이프!", "삼진!"을 브라우저 음성 합성(speechSynthesis)으로 짧게. 안 되면 소리 없이 넘어가게. iPad는 첫 터치 때 음성 합성을 한 번 빈 소리로 깨워줘.
- 타격음: 정타는 맑은 "딱!", 빗맞음은 둔하게, 파울은 짧게. 정타일 때 높은 "팅"을 아주 짧게 겹치기.
- 미트 소리: 포수 미트에 공이 꽂힐 때 "팡" 소리(구속이 빠를수록 크게).
- 함성: 지금 관중 소리에 더해, 안타·홈런·삼진·호수비 때 크기를 다르게.
- 3단계 소리 설정(켜기/끄기, 음량)을 모두 따르게.
```

확인: iPad에서 심판 콜이 나오는지(무음 스위치도 확인), 콜이 늦지 않은지.

## 9. 시즌 저장과 팀·선수 이름 편집

```
시즌을 며칠에 걸쳐 할 수 있게 저장하고, 팀·선수 이름을 내 마음대로 바꿀 수 있게 해줘.

시즌 저장:
- 시즌 진행(몇 번째 경기, 승패, 선수 기록)을 경기가 끝날 때마다 기기에 저장(localStorage, 못 하면 넘어가기).
- 타이틀 화면에 저장된 시즌이 있으면 "시즌 이어하기" 버튼, 새로 시작하면 확인 후 지우기.

이름 편집:
- 타이틀 화면에 "팀 편집" 버튼: 내 팀 이름, 팀 색, 타자 9명과 투수 이름을 바꿀 수 있는 창. 유니폼 가슴 글자와 전광판에도 반영.
- 바꾼 내용은 기기에 저장하고, "처음 이름으로 되돌리기" 버튼.
```

확인: 시즌 2경기째에서 새로고침해도 이어지는지, 바꾼 이름이 유니폼과 전광판에 나오는지.

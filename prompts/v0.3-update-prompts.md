# 풀카운트 v0.3 업데이트 프롬프트: "치고, 달리고, 잡는 손맛"

v0.2(한 경기)를 바탕으로, 비교 게임(나이트 베이스볼 3D)보다 **경기 시스템과 손맛**이 더 좋은 게임으로 만드는 코드 작업용 프롬프트다. 아래 프롬프트를 **순서대로 하나씩** 코드 작업에 붙여 넣는다. 한 단계가 끝날 때마다 iPad에서 열어 확인하고 다음 단계로 넘어간다.

- 매 프롬프트 맨 앞에 **0. 공통 머리말**을 같이 붙인다.
- 한 번에 여러 단계를 붙이지 않는다.
- 버그가 나오면 맨 아래 **버그 수정 프롬프트** 틀을 쓴다.

---

## 비교 요약 (2026-10-31)

### 새로 만들기 vs 업그레이드 → **업그레이드 추천**

- 두 게임 모두 웹 3D(나이트 베이스볼은 three.js, 풀카운트는 Babylon.js)라 그래픽 엔진 차이는 크지 않다.
- 차이는 대부분 **경기 시스템(도루·번트·수비 조작·리플레이·연출)이 있느냐 없느냐**이고, 이건 지금 코드 위에 하나씩 더할 수 있다.
- 풀카운트는 파일 16개로 나뉘어 있고 파일마다 맨 위에 숫자 조절표(`BAT_TUNING` 등)가 있다. 나이트 베이스볼은 118KB짜리 한 파일에 코드가 빽빽하게 붙어 있어, 코드 처음인 사람이 프롬프트로 계속 고쳐 나가기엔 풀카운트 구조가 훨씬 유리하다.
- 새로 만들면 v0.2에서 고친 것들(터치 좌표, 공 반짝임, 프레임 끊김, 수비·주루 애니메이션 등 PR 14개)을 다시 겪어야 한다.

### 나이트 베이스볼에 있고 풀카운트에 없는 것 (이번 계획에 넣는 것)

| 분야 | 나이트 베이스볼 | 풀카운트 v0.3에서 (오리지널 방식) |
| --- | --- | --- |
| 타격 손맛 | 정타 때 슬로모션, 화면 흔들림, 불꽃 | 히트 스톱 + 타이밍 미터(빠름/늦음 표시) + 정타 연출 → 1단계 |
| 리플레이 | 홈런 슬로 리플레이, 베이스 돌기, 불꽃놀이 | 하이라이트 리플레이(카메라 2컷) + 베이스 돌기 → 2단계 |
| 주루 | 도루 버튼, 번트 버튼 | 도루는 "스타트 타이밍" 손맛으로, 번트는 위치 탭 → 3단계 |
| 주루 | 안타 뒤 탭하면 한 베이스 더, 태그업 | 작은 다이아몬드에서 주자를 밀어 보내는 스와이프 → 4단계 |
| 수비 | 다이빙 캐치 버튼·스와이프, 홈런 훔치기 | 캐치 링(투구 링과 같은 감각)으로 타이밍 캐치 → 5단계 |
| 투구 | 견제, 고의사구, 투구 세기, 시프트 | 견제·고의사구·컴퓨터 주자 도루·몸에 맞는 공 → 6단계 |
| 선수 개성 | 타자별 9칸 핫존 | 핫존을 화면이 아닌 타자 카드에만 작게 + 발·어깨 개성 → 7단계 |
| 분위기 | 바람, 실책, 찬스 때 오르간 | 바람, 실책(E), 찬스 연출, 코드로 만든 짧은 응원 멜로디 → 8단계 |
| 기록 | 시즌 기록실, 명예의 전당, 최고 점수 | 한 경기 MVP·하이라이트·개인 최고 기록 → 9단계 |

### 일부러 따라 하지 않는 것

- **실제 구단·선수 이름**: 나이트 베이스볼은 실제 프로야구 팀과 선수 이름을 쓴다. 풀카운트는 지금처럼 가상 팀(바다 고래즈, 숲속 여우스)을 유지한다.
- **노림수(구종 예측) 버튼**: 수 싸움 요소라 프로젝트 방향과 맞지 않는다.
- **시즌 모드, 홈런더비 같은 다른 모드**: 한 경기 모드 하나만 둔다는 원칙 유지(2026-10-31 사용자 결정).
- **화면 가운데를 덮는 핫존 격자**: 공이 잘 안 보이게 만든다. 풀카운트는 공이 잘 보이는 화면을 지킨다.
- 벤치 클리어링, 무작위 보크 같은 운에 맡기는 이벤트.

### 풀카운트가 이미 더 나은 점 (지키기)

- **투구가 실력 게임**: 링이 줄어드는 타이밍에 손을 떼는 방식이라 손맛이 있다. 나이트 베이스볼은 드래그해서 떼면 끝이다.
- **타격도 위치가 중요**: 공이 있는 곳을 탭해야 한다. 나이트 베이스볼은 화면 아무 데나 타이밍만 맞추면 된다.
- 시작 메뉴 설정(3/9이닝, 낮/밤, 루키/프로, 소리 음량), 깔끔한 화면, 숫자만 바꿔 조절하는 구조.

## 0. 공통 머리말 (매번 맨 앞에 붙이기)

```
나는 개발이 처음인 사람이고, iPad Safari에서 혼자 플레이할 야구 게임 "풀카운트"를 만들고 있어.
- 저장소: myongg14/fullcount. 현재 코드는 v0.2(한 경기 모드). index.html이 Babylon.js 7.20.0(jsDelivr)을 불러온 뒤 js/ 아래 파일들을 순서대로 불러와. 빌드 도구 없음.
- 파일 역할은 README.md에 정리돼 있어. 먼저 README.md와 관련 파일을 읽고 시작해줘.
- 플랫폼: iPad Safari, 가로 화면, 터치 전용. 앱 설치 없이 웹페이지로 실행.
- 그림 스타일: 카툰 3D. 실존 구단·선수·로고는 쓰지 않고 가상 팀을 쓴다.
- 게임 성격: 구종 예측 같은 수 싸움 없이, 타이밍과 터치 조준으로 치고 던지는 손맛 중심. 모드는 "한 경기" 하나뿐.
- 외부 파일(이미지, 소리, 3D 모델)은 다른 서버에서 불러오지 말고, 코드로 만들어줘.
- GitHub Pages(https://myongg14.github.io/fullcount/)로 iPad에서 열어. index.html은 완전한 HTML 문서로 유지하고, CSS의 [hidden] { display: none !important; } 규칙을 지우지 마.
- 새로 조절할 숫자는 해당 파일 맨 위 설정표(예: BAT_TUNING, PLAY_TUNING)에 한국어 설명과 함께 넣어줘.
- 출시하지 않는 개인 프로젝트라 수익화, 로그인, 서버는 필요 없어.

작업 방식:
- 이번 단계에서 요청한 것만 바꾸고, 이미 되는 기능은 망가뜨리지 마.
- 새 버튼은 그 버튼이 필요한 상황에만 보이게 하고, 손가락으로 누르기 쉽게 48px 이상.
- 무엇을 왜 바꿨는지 쉬운 말로 짧게 설명하고, README.md 파일 설명도 맞게 고쳐줘.
- 끝나면 iPad에서 직접 확인할 항목을 체크리스트로 알려줘.
- 작업은 claude/v0.3-단계이름 브랜치에 커밋하고 푸시해줘.
```

## 1. 타격 손맛: 히트 스톱, 타이밍 미터, 정타 연출

```
공을 맞혔을 때 "딱!" 하는 손맛이 더 크게 느껴지게 해줘. 판정 규칙은 바꾸지 말고 보여 주는 것만 바꿔.

- 히트 스톱: 공을 맞힌 순간 화면 전체를 아주 잠깐 멈춰줘. 정타는 0.09초, 보통 타구는 0.05초, 빗맞음·파울은 멈추지 않음.
- 카메라 펀치: 정타일 때 카메라가 0.15초 동안 살짝 흔들리고 시야각이 잠깐 좁아졌다 돌아오게.
- 불꽃: 맞은 자리에서 작은 빛 조각이 튀게. 정타는 많고 밝게, 보통은 적게. 파티클은 한 번에 200개를 넘지 않게 해서 iPad가 느려지지 않게.
- 큰 타구 슬로모션: 타구 속도가 아주 빠른 정타(예: 160km/h 이상)는 맞은 뒤 0.4초 동안 공이 절반 속도로 날아가게.
- 타이밍 미터: 스윙할 때마다 화면 아래에 가로 막대를 잠깐 띄워서, 가운데(완벽)에서 얼마나 빨랐는지/늦었는지 점으로 보여줘. 글자로도 "완벽!", "조금 빠름", "늦음"처럼. 헛스윙이어도 보여줘서 다음에 맞출 수 있게.
- 숫자(멈추는 시간, 흔들림 세기, 슬로모션 기준)는 batting.js 맨 위 BAT_TUNING 옆에 HIT_FEEL 설정표로 넣어줘.
- 소리: 정타일 때 기존 타격음 위에 더 높은 "팅" 소리를 아주 짧게 겹쳐줘.
```

확인: 정타 때 화면이 아주 잠깐 멈추는 느낌이 나는지, 너무 길어서 답답하지 않은지, 타이밍 미터가 공을 가리지 않는지.

## 2. 하이라이트 리플레이와 홈런 베이스 돌기

```
홈런과 큰 장타가 나오면 다시 보고 싶게 만들어줘.

- 타구가 나는 동안 공 위치를 기록해 두고, 홈런이나 2루타 이상이면 플레이가 끝난 뒤 "하이라이트" 다시 보기를 자동으로 틀어줘.
- 다시 보기는 카메라 2컷: 1컷은 타자 옆에서 맞는 순간을 슬로로(약 1초), 2컷은 공을 뒤쫓는 카메라로 담장 넘어가는 장면까지. 화면 위에 "하이라이트 · 비거리 125m" 같은 표시.
- 아무 데나 탭하면 바로 건너뛰기.
- 홈런이면 다시 보기 전에 타자가 1·2·3루를 돌아 홈으로 들어오는 장면을 보여줘(기존 빨리 감기 버튼 유지). 홈에 들어올 때 팀 동료 몇 명이 홈 근처에서 맞이하게.
- 밤 경기 홈런이면 외야 위 하늘에 불꽃놀이(코드로 만든 빛 조각)를 2~3초.
- 메뉴에 "하이라이트 다시 보기: 켜기/끄기"를 추가하고 설정을 기억해줘.
```

확인: 홈런 뒤 다시 보기가 나오는지, 탭하면 바로 넘어가는지, 다시 보기 중에 경기 상태(점수, 주자)가 꼬이지 않는지.

## 3. 도루(스타트 타이밍)와 번트

```
내가 공격할 때 타격 말고도 할 수 있는 게 생기게, 도루와 번트를 넣어줘. 둘 다 손맛(타이밍)으로 결정되게 해줘.

도루:
- 1루나 2루에 주자가 있고 앞 베이스가 비어 있으면, 화면 오른쪽 아래에 "도루" 버튼이 보이게.
- 버튼을 누르고 있으면 주자가 리드를 크게 잡는다. 투수가 다리를 드는 순간(와인드업 시작)에 손을 떼면 "좋은 스타트!", 너무 일찍 떼면 "견제에 걸릴 위험", 늦게 떼면 "늦은 스타트".
- 성공 확률 = 스타트 타이밍 + 주자 발 빠르기 + 투구 속도(느린 공일수록 유리). 숫자는 play.js 맨 위 STEAL_TUNING에.
- 포수가 2루(또는 3루)로 던지고 주자가 슬라이딩하는 장면을 기존 수비·주루 애니메이션으로 보여주고, "도루 성공! / 도루 실패" 판정.
- 도루를 시도한 공에 내가 스윙하지 않으면 그대로 도루만 판정, 스윙해서 맞히면 타구 처리(주자는 이미 뛰는 중).

번트:
- 타격 화면에 "번트" 버튼(켜고 끄기). 켜면 타자가 번트 자세를 잡는다.
- 번트일 때는 공이 오는 순간 탭한 위치(왼쪽/가운데/오른쪽)로 공이 굴러간다. 타이밍 판정 폭은 일반 스윙보다 넓고, 대신 타구가 약하다.
- 결과: 대부분 희생번트(타자 아웃, 주자 진루), 발 빠른 타자는 가끔 번트 안타, 높은 공을 대면 뜬공 아웃.
```

확인: 도루 버튼이 주자가 있을 때만 보이는지, 손 떼는 타이밍에 따라 결과가 달라지는지, 번트로 주자가 진루하는지.

## 4. 안타 뒤 추가 진루와 태그업(스와이프)

```
안타나 뜬공이 났을 때 주자를 내가 직접 보낼지 말지 정하게 해줘.

- 타구가 외야로 가면 화면 오른쪽 위에 작은 다이아몬드(주자 위치)를 크게 띄워줘.
- 안타일 때: 주자가 기본 진루를 하는 동안, 다이아몬드 위 주자 아이콘을 다음 베이스 쪽으로 밀면(스와이프) 한 베이스 더 달린다. 성공 확률은 타구가 떨어진 거리, 주자 발, 공을 잡은 외야수 어깨로 정해. 보낼 수 있는 시간은 1.5초 정도, 그 안에 안 밀면 기본 진루로 끝.
- 화면에 "한 베이스 더?" 안내와 위험도(안전/아슬아슬/위험)를 색으로.
- 뜬공 아웃이고 0·1아웃에 3루(또는 2루) 주자가 있으면: 외야수가 공을 잡는 순간 주자를 밀면 태그업. 잡기 전에 밀면 "너무 빨라요" 하고 귀루.
- 결과는 기존처럼 판정 코드가 먼저 정하고, 수비수 송구와 주자 슬라이딩 애니메이션으로 보여줘. "세이프! / 홈에서 아웃!" 판정과 점수 반영.
- 내가 수비할 때(투구 모드)는 컴퓨터 주자가 같은 규칙으로 가끔 한 베이스 더 달리게.
```

확인: 안타 뒤 스와이프로 주자가 더 달리는지, 태그업 타이밍이 잡는 순간 기준으로 판정되는지, 3아웃이면 득점이 안 되는지.

## 5. 수비 캐치 링: 다이빙·점프 캐치, 홈런 훔치기

```
내가 수비할 때(투구 모드) 타구를 그냥 보기만 하지 말고, 아슬아슬한 타구는 내가 직접 잡게 해줘. 투구할 때 쓰는 "줄어드는 링"과 같은 감각으로.

- 컴퓨터 타자가 친 공이 수비수가 그냥은 못 잡는 아슬아슬한 거리(지금 다이빙 판정 기준 근처)로 가면, 공이 떨어질 곳에 흰 링과 줄어드는 노란 링을 띄워줘.
- 노란 링이 흰 링과 겹칠 때 그 링을 탭하면 다이빙 캐치(낮은 공) 또는 점프 캐치(담장 근처 높은 공). 많이 빗나가면 공을 놓치고 안타.
- 담장을 살짝 넘어가는 홈런(담장 위 2m 이내)은 외야수가 담장 앞에서 점프하고, 링을 맞추면 "홈런 훔치기!"로 아웃. 성공률은 낮게.
- 슬로모션: 링이 뜨면 시간이 0.5배로 느려져서 맞출 여유가 있게. 루키 난이도에서는 링이 더 천천히 줄어들게.
- 잡으면 큰 함성, 실패하면 짧은 탄식 소리.
- 그냥 잡을 수 있는 공, 그냥 못 잡는 공에는 링을 띄우지 마. 한 경기에 몇 번만 나오는 특별한 순간이 되게.
- 숫자(링 띄우는 거리 범위, 성공 폭, 슬로 배율)는 play.js 맨 위 CATCH_TUNING에.
```

확인: 링이 너무 자주 뜨지 않는지, 링을 맞추면 잡고 놓치면 안타가 되는지, 홈런 훔치기 장면이 자연스러운지.

## 6. 투구 쪽 추가: 견제, 고의사구, 컴퓨터 주자 도루, 몸에 맞는 공

```
내가 투수일 때 주자와 관련된 플레이를 넣어줘. 3단계 도루 시스템을 그대로 이용해.

- 컴퓨터 주자 도루: 컴퓨터 팀 주자가 발 빠르기에 따라 가끔 도루를 시도해. 투수가 와인드업할 때 주자가 뛰기 시작하는 게 보이게.
- 견제: 주자가 있으면 구종 카드 옆에 "견제" 버튼. 누르면 주자가 있는 베이스(여러 명이면 베이스를 탭해서 고르기)로 던진다. 주자가 리드를 크게 잡았거나 도루하려던 참이면 아웃 확률이 높고, 아니면 그냥 귀루. 연속 견제는 2번까지.
- 고의사구: 구종 카드 옆 "고의사구" 버튼. 누르면 확인 없이 바로 타자를 1루로 보낸다(주자는 밀어내기만).
- 몸에 맞는 공: 내 투구나 컴퓨터 투구가 타자 몸 쪽으로 크게 빠지면 일정 확률로 몸에 맞는 공. 타자가 움찔하는 동작 + 1루로.
- 투수 체력이 낮아지면 구속이 조금씩 떨어지고, 화면에 체력 막대를 투수 이름 옆에 작게 보여줘.
- 컴퓨터 팀 투수도 체력이 떨어지면 자동으로 교체되고 "투수 교체" 배너가 나오게.
```

확인: 견제로 주자를 잡을 수 있는지, 고의사구가 바로 처리되는지, 컴퓨터 투수가 경기 중에 바뀌는지.

## 7. 선수 개성: 핫존, 빠른 발, 강한 어깨

```
선수마다 개성이 더 느껴지게 해줘. 수 싸움 게임이 되지 않게, 정보는 작게만 보여줘.

- 핫존: 타자마다 스트라이크존 9칸 중 잘 치는 칸 2~3개와 약한 칸 1~2개를 정해줘(teams.js, 이름으로 고정되게). 잘 치는 칸의 공을 맞히면 타구가 조금 더 세고, 약한 칸은 조금 약하게.
- 보여 주는 곳: 화면 가운데 존 위가 아니라, 타자 정보 카드(화면 구석)에 작은 9칸 그림으로만. 빨강=강함, 파랑=약함.
- 발 빠른 선수: 내야 땅볼 때 가끔 내야 안타, 도루·추가 진루 성공률 상승. 카드에 "빠른 발" 표시.
- 강한 어깨 외야수: 추가 진루·태그업 때 아웃 확률 상승. 송구가 눈에 띄게 빠르게.
- 팀마다 홈런 타자 1~2명, 교타자 몇 명처럼 타순에 역할이 보이게 능력치를 다시 다듬어줘.
```

확인: 타자 카드에 핫존 그림이 보이는지, 공이 잘 보이는 화면이 그대로인지.

---

## 8. 경기 분위기: 바람, 실책, 찬스 연출, 응원 멜로디

```
경기마다 조금씩 다르고, 중요한 순간은 더 긴장되게 해줘.

- 바람: 경기 시작할 때 바람 방향과 세기(0~4m/s)를 정하고, 화면 구석에 화살표와 "순풍/역풍"으로 표시. 뜬공 비거리에 조금 영향.
- 실책: 아주 낮은 확률로 수비수가 땅볼을 놓치거나 송구가 빗나가 타자가 살아나가게. 전광판 R·H 옆에 E(실책) 칸 추가.
- 찬스 연출: 내 팀 공격에서 득점권(2·3루)에 주자가 있고 2아웃이거나 동점·1점 차 7회 이후면 "찬스!" 표시, 관중이 박자에 맞춰 박수(소리), 화면 가장자리가 은은하게 빛나게. 수비할 때 같은 상황이면 "위기!"로.
- 응원 멜로디: 코드로 만든 짧은 멜로디(실제 응원가를 따라 하지 말고 새로 만든 4~6음) 3가지: 찬스, 홈런, 삼진 잡았을 때. 소리 설정을 따르게.
- 7회에는 관중이 잠깐 일어나 손을 흔드는 동작(관중 인스턴스를 위아래로 흔드는 정도로 가볍게).
```

확인: 바람 표시가 보이는지, 찬스 때 분위기가 달라지는지, iPad가 느려지지 않는지.

## 9. 결과 화면 강화: MVP, 하이라이트, 개인 최고 기록

```
경기가 끝났을 때 다시 하고 싶어지게 결과 화면을 키워줘.

- 경기 MVP: 내 팀에서 가장 잘한 선수(타점·홈런·안타·탈삼진으로 점수 계산)를 카툰 선수 모델로 크게 보여주고 오늘 기록.
- 오늘의 하이라이트: 경기 중 큰 장면(홈런, 다이빙 캐치, 도루, 역전 등)을 자동으로 기록해 두었다가 목록으로. 각 줄을 탭하면 2단계 리플레이가 있으면 그 장면을 다시 재생.
- 개인 최고 기록: 이 기기에 저장(localStorage, 못 하면 그냥 넘어가기). 최장 홈런, 가장 빠른 타구, 한 경기 최다 득점, 최다 탈삼진, 다이빙 캐치 수, 통산 승·패. 새 기록이면 "새 기록!" 배지.
- 시작 메뉴에 "내 기록" 버튼을 추가해서 개인 최고 기록을 볼 수 있게.
- 박스 스코어에 E(실책) 칸과 도루 기록 추가.
```

확인: 결과 화면에 MVP와 하이라이트가 보이는지, 새로고침해도 기록이 남는지.

## 10. 화면 정리와 iPad 성능 점검

```
v0.3에서 버튼과 연출이 많이 늘었어. 마무리로 정리해줘.

- 화면에 동시에 보이는 버튼이 많아지지 않게, 상황(타격/투구/수비 중/주자 있음)에 따라 필요한 버튼만 보이게 다시 확인.
- 엄지로 누르기 쉬운 위치(화면 아래 양옆)에 자주 쓰는 버튼 배치. 공이 지나가는 화면 가운데는 비워두기.
- iPad에서 프레임이 떨어지지 않게: 파티클 수, 리플레이 기록 길이, 그림자, 관중 수를 점검하고, 느린 기기면 자동으로 효과를 줄이는 "가벼운 그래픽" 설정을 메뉴에 추가.
- 처음 하는 사람을 위해 시작 메뉴에 "조작법" 버튼: 타격·투구·도루·추가 진루·캐치 링을 그림 한 장씩으로 짧게.
- README.md를 v0.3 기준으로 정리.
```

확인: 9이닝 한 경기를 끝까지 했을 때 끊김이 없는지, 처음 보는 사람이 조작법만 보고 플레이할 수 있는지.

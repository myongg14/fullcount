# 풀카운트 v0.3 업데이트 프롬프트: 타자·투수·수비 전부 끌어올리기

v0.2(한 경기)를 바탕으로, 비교 게임(나이트 베이스볼 3D)보다 **타자, 투수, 수비, 주루 모든 분야**에서 더 깊고 손맛 있는 게임으로 만드는 코드 작업용 프롬프트다. 아래 프롬프트를 **순서대로 하나씩** 코드 작업에 붙여 넣는다. 한 단계가 끝날 때마다 iPad에서 열어 확인하고 다음 단계로 넘어간다.

- 매 프롬프트 맨 앞에 **0. 공통 머리말**을 같이 붙인다.
- 한 번에 여러 단계를 붙이지 않는다.
- 버그가 나오면 맨 아래 **버그 수정 프롬프트** 틀을 쓴다.

## 비교 요약 (2026-10-31)

### 새로 만들기 vs 업그레이드 → **업그레이드 추천**

- 두 게임 모두 웹 3D(나이트 베이스볼은 three.js, 풀카운트는 Babylon.js)라 엔진 차이는 크지 않다. 차이는 **각 분야의 시스템 깊이**다.
- 풀카운트는 파일 16개로 나뉘어 있고 파일마다 맨 위에 숫자 조절표가 있다. 나이트 베이스볼은 118KB짜리 한 파일에 코드가 빽빽해서, 코드 처음인 사람이 프롬프트로 계속 고쳐 나가기엔 풀카운트 구조가 훨씬 유리하다.
- 새로 만들면 v0.2에서 고친 것들(터치 좌표, 공 반짝임, 프레임 끊김, 수비·주루 애니메이션 등 PR 14개)을 다시 겪어야 한다.
- 모드는 **한 경기 모드 하나만** 유지한다(2026-10-31 사용자 결정). 시즌, 홈런더비 같은 다른 모드는 넣지 않는다.

### 일부러 따라 하지 않는 것

- **실제 구단·선수 이름**: 나이트 베이스볼은 실제 프로야구 팀과 선수 이름을 쓴다. 풀카운트는 가상 팀을 유지한다.
- **노림수(구종 예측) 버튼**: 수 싸움 요소라 프로젝트 방향과 맞지 않는다.
- **시즌·홈런더비 모드**: 한 경기 모드 하나만 유지.
- **화면 가운데를 덮는 핫존 격자**: 공이 잘 안 보이게 만든다.
- 벤치 클리어링, 무작위 보크 같은 운에 맡기는 이벤트.

### 풀카운트가 이미 더 나은 점 (지키기)

- **투구가 실력 게임**: 링이 줄어드는 타이밍에 손을 떼는 방식. 나이트 베이스볼은 드래그해서 떼면 끝이다.
- **타격도 위치가 중요**: 공이 있는 곳을 탭해야 하고, 타이밍이 빠르면 당겨치고 늦으면 밀어친다. 나이트 베이스볼은 화면 아무 데나 타이밍만 맞추면 된다.
- 구종 17개와 구종별 숙련도, 시작 메뉴 설정(3/9이닝, 낮/밤, 루키/프로, 소리), 숫자만 바꿔 조절하는 구조.

```
나는 개발이 처음인 사람이고, iPad Safari에서 혼자 플레이할 야구 게임 "풀카운트"를 만들고 있어.
- 저장소: myongg14/fullcount. 현재 코드는 v0.2(한 경기 모드). index.html이 Babylon.js 7.20.0(jsDelivr)을 불러온 뒤 js/ 아래 파일들을 순서대로 불러와. 빌드 도구 없음.
- 파일 역할은 README.md에 정리돼 있어. 먼저 README.md와 관련 파일을 읽고 시작해줘.
- 플랫폼: iPad Safari, 가로 화면, 터치 전용. 앱 설치 없이 웹페이지로 실행.
- 그림 스타일: 카툰 3D. 실존 구단·선수·로고는 쓰지 않고 가상 팀을 쓴다.
- 게임 성격: 구종 예측 같은 수 싸움 없이, 타이밍과 터치 조준으로 치고 던지는 손맛 중심. 모드는 "한 경기" 하나뿐.
- 외부 파일(이미지, 소리, 3D 모델)은 다른 서버에서 불러오지 말고, 코드로 만들어줘.
- GitHub Pages(https://myongg14.github.io/fullcount/)로 iPad에서 열어. index.html은 완전한 HTML 문서로 유지하고, CSS의 [hidden] { display: none !important; } 규칙을 지우지 마.
- 새로 조절할 숫자는 해당 파일 맨 위 설정표(예: BAT_TUNING, PLAY_TUNING)에 한국어 설명과 함께 넣어줘.
- 출시하지 않는 개인 프로젝트라 수익화, 로그인, 서버는 필요 없어.

작업 방식:
- 이번 단계에서 요청한 것만 바꾸고, 이미 되는 기능은 망가뜨리지 마.
- 새 버튼은 그 버튼이 필요한 상황에만 보이게 하고, 손가락으로 누르기 쉽게 48px 이상.
- 무엇을 왜 바꿨는지 쉬운 말로 짧게 설명하고, README.md 파일 설명도 맞게 고쳐줘.
- 끝나면 iPad에서 직접 확인할 항목을 체크리스트로 알려줘.
- 작업은 claude/v0.3-단계이름 브랜치에 커밋하고 푸시해줘.
```

## 1. 타격 손맛: 히트 스톱, 타이밍 미터, 투구 위치 표시, 타격 카메라·스윙 동작

```
공을 맞혔을 때와 놓쳤을 때 모두 손맛과 이유가 확실히 느껴지게 해줘. 판정 규칙(맞는 폭, 타구 계산)은 바꾸지 말고 보여 주는 것만 바꿔.

정타 연출:
- 히트 스톱: 맞힌 순간 화면 전체를 아주 잠깐 멈춤. 정타 0.09초, 보통 0.05초, 빗맞음·파울은 멈추지 않음.
- 카메라 펀치: 정타일 때 0.15초 동안 살짝 흔들리고 시야각이 잠깐 좁아졌다 돌아오게.
- 불꽃: 맞은 자리에서 빛 조각이 튀게(정타는 많고 밝게). 한 번에 200개 이하.
- 큰 타구 슬로모션: 타구 속도 160km/h 이상 정타는 맞은 뒤 0.4초 동안 공이 절반 속도로.
- 정타일 때 기존 타격음 위에 높은 "팅" 소리를 아주 짧게 겹치기.

놓쳤을 때 이유 보여 주기:
- 타이밍 미터: 스윙할 때마다 화면 아래에 가로 막대를 잠깐 띄워 완벽(가운데)에서 얼마나 빨랐는지/늦었는지 점으로. "완벽!", "조금 빠름", "늦음" 글자도.
- 투구 위치 표시: 공이 홈플레이트를 지나간 자리에 작은 점(존 안은 초록, 밖은 빨강)을 1초 남기고, 내가 탭한 자리에는 흰 X. 위치가 얼마나 어긋났는지 바로 보이게. 다음 공이 오면 지워.

타격 화면 다듬기:
- 타자를 반투명 대신 불투명하게 하되, 공이 지나가는 길을 가리지 않도록 카메라를 타자 어깨 뒤 조금 옆으로 옮겨줘. main.js 맨 위에 BAT_VIEW 설정표로.
- 스윙 동작: 지금 0.18초 단순 회전을 "발 내딛기 → 허리 회전 → 배트 → 팔로스루" 순서로 0.35초 정도에 보이게. 헛스윙은 몸이 한 바퀴 더 돌 듯 크게, 정타는 팔로스루를 끝까지.
- 홈런이면 타자가 배트를 옆으로 던지고 걸어 나가는 짧은 동작.
- 숫자(멈추는 시간, 흔들림 세기, 슬로모션 기준)는 batting.js 맨 위 HIT_FEEL 설정표에.
```

확인: 정타 때 아주 잠깐 멈추는 느낌이 나는지(답답하지 않은지), 헛스윙 뒤 왜 놓쳤는지 보이는지, 새 카메라에서 공이 잘 보이는지.

## 2. 스윙 3가지, 타자 카드와 핫존, 컴퓨터 투수 완급 조절

```
타석마다 내가 고를 것과 타자마다 다른 점이 생기게 해줘. 수 싸움 게임이 되지 않게, 고르는 건 스윙 방식뿐이야.

스윙 3가지:
- 화면 아래 버튼을 "컨택 / 파워 / 번트" 3개 중 하나 고르는 방식으로 바꿔줘(지금 파워 스윙 버튼 대신).
- 컨택: 맞는 시간·위치 폭이 넓고 타구가 조금 약함. 2스트라이크에서 아슬아슬한 공은 파울로 걷어낼 확률이 높음.
- 파워: 지금 파워 스윙과 같음(폭 좁고 타구 셈).
- 번트: 타자가 번트 자세. 공이 오는 순간 탭한 위치(왼쪽/가운데/오른쪽)로 공이 굴러감. 대부분 희생번트(타자 아웃, 주자 진루), 발 빠른 타자는 가끔 번트 안타, 높은 공을 대면 뜬공 아웃. 주자 진루는 기존 수비·주루 애니메이션으로.
- 고른 스윙은 타석이 끝나면 컨택으로 돌아가게(설정에서 "유지"로 바꿀 수 있게).

타자 카드와 핫존:
- 화면 구석에 지금 타자 카드: 이름, 등번호, 좌/우타, 오늘 성적(3타수 1안타), 특징 한 단어(장타자/교타자/빠른 발).
- 타자마다 스트라이크존 9칸 중 잘 치는 칸 2~3개, 약한 칸 1~2개(teams.js에 고정). 잘 치는 칸 공은 타구가 조금 세고, 약한 칸은 조금 약하게.
- 핫존은 화면 가운데가 아니라 타자 카드 안에 작은 9칸 그림으로만(빨강 강함, 파랑 약함). 내가 투수일 때도 상대 타자 카드에 보여서 어디로 던질지 참고하게.
- 팀마다 장타자 2명, 교타자 3명, 발 빠른 선수 2명처럼 역할이 드러나게 능력치 다듬기.

컴퓨터 투수 완급 조절:
- 컴퓨터 투수가 같은 구종만 연달아 던지지 않게, 빠른 공 다음에 느린 공을 섞는 비율을 투수마다 다르게.
- 2스트라이크에서는 존 밖으로 빠지는 결정구 비율을 높이고, 3볼에서는 존 안으로.
- 숫자는 pitching.js 맨 위 CPU_PITCH 설정표에.
```

확인: 스윙 버튼 3개가 잘 바뀌는지, 번트로 주자가 진루하는지, 타자 카드가 공을 가리지 않는지.

## 3. 투구폼 4가지, 결정구, 투수진 5명

```
투수마다 던지는 모습과 공이 확실히 다르게 해줘.

투구폼:
- 투구폼 4가지: 오버핸드, 스리쿼터, 사이드암, 언더핸드. teams.js 투수 데이터에 form 항목 추가.
- 폼마다 와인드업과 팔 각도 애니메이션이 다르고(players.js), 공이 손을 떠나는 높이·좌우 위치가 달라.
  예: 오버핸드 높고 가운데, 사이드암 낮고 옆, 언더핸드 아주 낮게 떠오르듯.
- 궤적 차이: 사이드암은 좌우 변화가 더 크고, 언더핸드는 공이 아래에서 떠오르듯 들어오고 구속이 느림. pitching.js 맨 위 FORM_TUNING 표로.
- 내가 투수일 때(투수 뒤 시점)와 타자일 때(컴퓨터 투수) 모두 폼 차이가 잘 보이게.

결정구:
- 투수마다 결정구 1개: 그 구종은 변화량 1.25배, 카드에 ★ 표시와 별명(예: "칼날 슬라이더", "낙하산 포크" 같은 새 이름).

투수진:
- 팀마다 투수 5명: 선발 1, 중계 3, 마무리 1. 가상 이름, 폼과 결정구가 서로 겹치지 않게.
- 투수 교체 창에서 각 투수의 폼, 결정구, 체력이 보이게.
```

확인: 투수마다 폼이 눈에 띄게 다른지, 언더핸드 공이 아래에서 올라오는지, 결정구가 더 크게 꺾이는지.

## 4. 투구 손맛: 손목 스냅 세기, 체력, 컴퓨터 투수 교체

```
투구에 손맛을 하나 더 넣어줘. 지금 링 타이밍(제구)은 그대로 두고, 세기를 정하는 동작을 추가해.

손목 스냅(세기):
- 지금은 링이 맞을 때 손을 떼면 던져. 이걸 "링이 맞을 때 손가락을 위로 튕기듯 밀면서 뗀다"로 바꿔줘.
- 위로 빠르게 튕길수록 구속이 빠르고(최대 +4km/h), 대신 링 타이밍이 조금만 어긋나도 크게 빗나감. 살살 떼면 구속 −3km/h, 제구는 안정.
- 튕기지 않고 그냥 떼도 지금처럼 던져지게(보통 세기).
- 던진 뒤 화면에 "제구 ●●●○ / 세기 ●●○○"처럼 짧게 결과.
- 숫자는 pitching.js 맨 위 SNAP_TUNING 표에.

체력:
- 투수 체력이 떨어질수록 구속이 서서히 떨어지고(최대 −6km/h), 제구 흔들림이 커짐. 세게 던질수록 체력이 더 많이 줄어듦.
- 투수 이름 옆에 작은 체력 막대(초록 → 노랑 → 빨강).

컴퓨터 투수:
- 컴퓨터 팀 투수도 체력이 떨어지면 자동 교체, 7회 이후 접전이면 마무리 투수 등판. "투수 교체" 배너와 새 투수가 걸어 나오는 짧은 장면.
- 컴퓨터 타자: 존 끝 공에 체크 스윙(배트가 반쯤 나오다 멈춤) 동작, 헛스윙 삼진은 크게 휘두르는 동작으로 내 투구 손맛이 보이게.
```

확인: 튕겨서 던지면 구속이 오르는지, 그냥 떼도 던져지는지, 체력이 낮을 때 공이 느려지는지.

## 5. 수비 캐치 링: 다이빙·점프 캐치, 홈런 훔치기

```
내가 수비할 때(투구 모드) 아슬아슬한 타구는 내가 직접 잡게 해줘. 투구할 때 쓰는 "줄어드는 링"과 같은 감각으로.

- 컴퓨터 타자가 친 공이 수비수가 그냥은 못 잡는 아슬아슬한 거리(지금 다이빙 판정 근처)로 가면, 공이 떨어질 곳에 흰 링과 줄어드는 노란 링.
- 노란 링이 흰 링과 겹칠 때 링을 탭하면 다이빙 캐치(낮은 공) 또는 점프 캐치(담장 근처 높은 공). 많이 빗나가면 공을 놓치고 안타.
- 담장을 살짝 넘어가는 홈런(담장 위 2m 이내)은 외야수가 담장 앞에서 점프, 링을 맞추면 "홈런 훔치기!" 아웃. 성공률 낮게.
- 링이 뜨면 시간이 0.5배로 느려짐. 루키 난이도는 링이 더 천천히 줄어듦.
- 잡으면 큰 함성, 실패하면 짧은 탄식.
- 쉽게 잡는 공, 절대 못 잡는 공에는 링을 띄우지 마. 한 경기에 몇 번만 나오는 특별한 순간이 되게.
- 숫자는 play.js 맨 위 CATCH_TUNING 표에.
```

확인: 링이 너무 자주 뜨지 않는지, 맞추면 잡고 놓치면 안타가 되는지, 홈런 훔치기 장면이 자연스러운지.

## 6. 송구 고르기, 수비 위치, 실책

```
수비할 때 캐치 말고도 내가 결정하는 순간을 만들어줘.

송구 고르기:
- 땅볼을 내야수가 잡는 순간, 주자가 있으면 화면의 베이스(1·2·3루·홈) 위에 큰 원 버튼이 뜨고 시간이 0.4배로 느려짐. 탭한 베이스로 송구.
- 판정은 송구 거리, 주자 발, 수비수 어깨로 정해. 병살을 노리면 2루 → 1루 순서로 자동 연결.
- 외야 뜬공 뒤 컴퓨터 주자가 태그업하면 홈/3루 버튼이 떠서 내가 송구할 곳을 고름.
- 1.2초 안에 안 고르면 지금처럼 컴퓨터가 알아서 가장 안전한 곳으로 던짐.
- 주자가 없으면 그냥 자동으로 1루 송구(버튼 안 띄움).

수비 위치:
- 투구 화면에 "수비 위치" 버튼 하나: 누를 때마다 기본 → 당겨치기 대비 → 전진 수비로 바뀜.
- 당겨치기 대비는 내야·외야가 타자 당기는 쪽으로 이동, 전진 수비는 내야가 앞으로(3루 주자 홈 승부에 유리, 대신 빠른 땅볼이 빠져나가기 쉬움).
- 컴퓨터 팀도 장타자 타석에 가끔 당겨치기 대비를 씀(내가 타자일 때 수비수 위치가 보이게).

실책:
- 아주 낮은 확률로 땅볼을 놓치거나 송구가 빗나가 타자가 살아남. 수비수 어깨·수비 능력이 낮을수록 조금 더 자주.
- 전광판 R·H 옆에 E(실책) 칸 추가.
```

확인: 땅볼 때 베이스 버튼이 뜨고 고른 곳으로 던지는지, 안 고르면 자동으로 처리되는지, 수비 위치가 바뀌는 게 보이는지.

## 7. 내 주루: 도루(스타트 타이밍), 추가 진루·태그업(스와이프)

```
내가 공격할 때 주자도 직접 움직이게 해줘. 모두 타이밍 손맛으로 결정되게.

도루:
- 1루나 2루에 주자가 있고 앞 베이스가 비어 있으면 화면 오른쪽 아래에 "도루" 버튼.
- 버튼을 누르고 있으면 주자가 리드를 크게 잡음. 투수가 다리를 드는 순간 손을 떼면 "좋은 스타트!", 너무 일찍 떼면 견제에 걸릴 위험, 늦으면 "늦은 스타트".
- 성공 확률 = 스타트 타이밍 + 주자 발 + 투구 속도(느린 공 유리) + 포수 어깨. 숫자는 play.js 맨 위 STEAL_TUNING에.
- 포수 송구와 주자 슬라이딩 장면, "도루 성공! / 도루 실패" 판정. 도루한 공에 스윙해서 맞히면 타구 처리.

추가 진루·태그업:
- 타구가 외야로 가면 화면 오른쪽 위에 작은 다이아몬드(주자 위치)를 크게.
- 안타: 주자가 기본 진루하는 동안 주자 아이콘을 다음 베이스 쪽으로 밀면(스와이프) 한 베이스 더. 확률은 타구 거리, 주자 발, 외야수 어깨. 1.5초 안에 안 밀면 기본 진루로 끝. 위험도(안전/아슬아슬/위험)를 색으로.
- 뜬공 아웃, 0·1아웃에 3루(또는 2루) 주자: 외야수가 잡는 순간 주자를 밀면 태그업. 잡기 전에 밀면 "너무 빨라요" 하고 귀루.
- 결과는 판정 코드가 먼저 정하고 송구·슬라이딩 애니메이션으로. "세이프! / 홈에서 아웃!"과 점수 반영.
```

확인: 도루 버튼이 주자가 있을 때만 보이는지, 손 떼는 타이밍에 따라 결과가 달라지는지, 스와이프로 주자가 더 달리는지, 3아웃이면 득점이 안 되는지.

## 8. 상대 주루 막기: 견제, 고의사구, 컴퓨터 도루, 몸에 맞는 공

```
내가 투수일 때 컴퓨터 주자와 대결하게 해줘. 7단계 도루 시스템을 재사용해.

- 컴퓨터 주자 도루: 발 빠른 주자가 가끔 리드를 크게 잡고(눈에 보이게), 와인드업 때 뛰기 시작. 포수 송구와 슬라이딩으로 판정.
- 견제: 주자가 있으면 구종 카드 옆 "견제" 버튼. 주자가 여러 명이면 베이스를 탭해서 고름. 주자가 리드를 크게 잡았거나 뛰려던 참이면 아웃 확률이 높고, 아니면 귀루. 연속 견제는 2번까지.
- 빠른 투구: 주자가 리드를 크게 잡았을 때 와인드업 없이 바로 던지는 "퀵 모션"(링이 더 빨리 줄어들어 제구가 조금 어려움). 도루 성공률을 낮춤.
- 고의사구: 구종 카드 옆 "고의사구" 버튼, 누르면 바로 타자 1루(주자는 밀어내기만).
- 몸에 맞는 공: 투구가 타자 몸 쪽으로 크게 빠지면 일정 확률로 몸에 맞는 공. 타자가 움찔하는 동작 + 1루로. 내가 타자일 때도 똑같이.
```

확인: 견제로 주자를 잡을 수 있는지, 퀵 모션 때 도루가 줄어드는지, 고의사구가 바로 처리되는지.

## 9. 하이라이트 리플레이와 경기 분위기

```
큰 장면은 다시 보고 싶게, 경기마다 조금씩 다르고 중요한 순간은 더 긴장되게 해줘.

리플레이:
- 타구가 나는 동안 공 위치를 기록해 두고, 홈런·2루타 이상·홈런 훔치기·홈 승부가 나오면 플레이가 끝난 뒤 하이라이트 다시 보기.
- 카메라 2컷: 1컷은 옆에서 맞는(또는 잡는) 순간을 슬로로 약 1초, 2컷은 공을 뒤쫓는 카메라. 화면 위에 "하이라이트 · 비거리 125m".
- 아무 데나 탭하면 바로 건너뛰기. 메뉴에 "하이라이트 다시 보기: 켜기/끄기"(설정 기억).
- 홈런이면 다시 보기 전에 타자가 베이스를 돌고 홈에서 팀 동료 몇 명이 맞이. 밤 경기면 외야 하늘에 불꽃놀이 2~3초.

분위기:
- 바람: 경기 시작 때 방향·세기(0~4m/s)를 정하고 구석에 화살표와 "순풍/역풍". 뜬공 비거리에 조금 영향.
- 찬스·위기: 내 공격에서 득점권 주자 + 2아웃, 또는 7회 이후 동점·1점 차면 "찬스!", 관중 박자 박수 소리, 화면 가장자리가 은은하게 빛남. 수비 때 같은 상황이면 "위기!".
- 응원 멜로디: 코드로 만든 짧은 멜로디(실제 응원가를 따라 하지 말고 새로 4~6음) 3가지: 찬스, 홈런, 삼진. 소리 설정을 따르게.
- 7회에 관중이 잠깐 일어나 손을 흔드는 동작(관중 인스턴스를 위아래로 흔드는 정도로 가볍게).
```

확인: 홈런 뒤 다시 보기가 나오고 탭하면 넘어가는지, 다시 보기 중에 점수·주자가 꼬이지 않는지, 찬스 때 분위기가 달라지는지.

## 10. 결과 화면 강화: MVP, 하이라이트, 개인 최고 기록

```
경기가 끝났을 때 다시 하고 싶어지게 결과 화면을 키워줘.

- 경기 MVP: 내 팀에서 가장 잘한 선수(타점·홈런·안타·탈삼진·호수비로 점수 계산)를 카툰 선수 모델로 크게, 오늘 기록과 함께.
- 오늘의 하이라이트: 경기 중 큰 장면(홈런, 다이빙 캐치, 홈런 훔치기, 도루, 견제사, 역전)을 자동 기록해 목록으로. 탭하면 9단계 리플레이가 남아 있는 장면은 다시 재생.
- 개인 최고 기록(이 기기 localStorage, 못 하면 넘어가기): 최장 홈런, 가장 빠른 타구, 최고 구속 삼진, 한 경기 최다 득점·탈삼진, 다이빙 캐치 수, 통산 승·패. 새 기록이면 "새 기록!" 배지.
- 시작 메뉴에 "내 기록" 버튼.
- 박스 스코어에 E(실책), 도루, 투수별 투구 수 추가.
```

확인: 결과 화면에 MVP와 하이라이트가 보이는지, 새로고침해도 기록이 남는지.

## 11. 화면 정리, 조작법, iPad 성능 점검

```
v0.3에서 버튼과 연출이 많이 늘었어. 마무리로 정리해줘.

- 상황(타격/투구/수비 중/주자 있음)에 따라 필요한 버튼만 보이는지 전부 다시 확인. 한 화면에 버튼이 5개를 넘지 않게.
- 엄지로 누르기 쉬운 위치(화면 아래 양옆)에 자주 쓰는 버튼. 공이 지나가는 화면 가운데는 비우기.
- iPad 프레임 점검: 파티클 수, 리플레이 기록 길이, 그림자, 관중 수. 느리면 자동으로 효과를 줄이는 "가벼운 그래픽" 설정을 메뉴에.
- 시작 메뉴에 "조작법" 버튼: 타격(스윙 3가지), 투구(링 + 손목 스냅), 수비(캐치 링·송구 고르기), 주루(도루·스와이프)를 그림 한 장씩으로 짧게.
- README.md를 v0.3 기준으로 정리.
```

확인: 9이닝 한 경기를 끝까지 했을 때 끊김이 없는지, 처음 보는 사람이 조작법만 보고 플레이할 수 있는지.

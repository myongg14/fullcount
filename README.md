# fullcount → 나이트 베이스볼 3D

iPad Safari에서 터치로 치고 던지는 3D 야구 게임. 혼자 만들고 혼자 플레이하는 개인 프로젝트다.

2026-10-31부터 이 저장소의 게임은 **나이트 베이스볼 3D**로 바뀌었다. 예전 풀카운트(Babylon.js)는 git 기록의 커밋 `a6df590`(PR #16 머지)에 그대로 남아 있다.

## iPad에서 열기

저장소 Settings → Pages에서 Source를 `main` 브랜치 `/ (root)`로 정하면 `https://myongg14.github.io/fullcount/` 주소로 열 수 있다. 빌드 도구는 없다. 파일을 고치고 올리면 그대로 반영된다.

## 파일 구성

`index.html`이 화면 틀(버튼, 점수판, 타이틀·종료 화면)을 담고, 모양은 `css/style.css`, 동작은 `js/` 폴더의 파일들이 맡는다. 3D 그리기는 three.js r128(cdnjs)을 쓴다.

자바스크립트 파일은 `index.html` 맨 아래에서 **아래 순서대로** 불러온다. 파일끼리 변수와 함수를 함께 쓰므로, 시작할 때 바로 실행되는 코드가 있는 파일은 순서를 바꾸면 안 된다. 경기 화면은 `main.js`가 마지막에 첫 프레임을 시작하면서 움직이기 시작한다.

그 밖의 파일:

- `css/style.css`: 화면 글자·버튼·창 모양
- `prompts/night-baseball-update-prompts.md`: 이 게임을 업그레이드하는 단계별 프롬프트(10단계). 코드 작업에 하나씩 붙여 넣는다.

### 자주 보는 이름

| 이름 | 뜻 |
| --- | --- |
| `phase` | 지금 단계: `title`(타이틀), `windup`(와인드업), `pitch`(공이 날아옴), `hit`(타구), `wait`(다음 투구 대기), `aim`(투수 조준), `anim`(견제 등 연출), `over`(경기 끝) |
| `pitcherMode` | 지금 내가 투수(수비)인지. 정식 경기는 초에 타자, 말에 투수 |
| `balls`, `strikes`, `outs` | 볼·스트라이크·아웃 수 |
| `bases` | 주자 `[1루, 2루, 3루]`. 0이면 비어 있고, 숫자는 그 주자의 타순+1 |
| `pitch`, `swing`, `hit` | 지금 투구·스윙·타구 정보 |
| `now` | 게임 시계(ms) |
| `CFG` | 경기 확률 설정표(`core.js` 맨 위) |

## 성능 조절

iPad에서 끊기면 `js/scene.js` 맨 위 `PERF` 설정표의 숫자를 낮춘다. 주소 끝에 `?fps`를 붙여 열면(`https://myongg14.github.io/fullcount/?fps`) 오른쪽 아래에 초당 프레임 수가 보인다.

## 게임 내용

- 정식 경기(3·6·9회 중 고름, 시즌은 9회): 초에는 타자, 말에는 투수 시점으로 번갈아 플레이
- 타이틀 화면 설정: 난이도(루키는 공이 15% 느리고 스윙 판정 폭이 넓으며 컴퓨터 타자가 약함 / 프로), 이닝, 시간(자동·낮·저녁·밤), 소리 켜기/끄기·음량. 고른 값은 기기에 기억
- 타석 화면: 스트라이크존은 얇은 테두리만(설정 '존 위 핫존'을 켜면 옅은 색칸). 핫존은 오른쪽 위 타자 카드 안 작은 9칸으로. 공이 지나간 자리는 공이 지나간 뒤에만 표시. 번트·도루는 왼쪽 아래, 스윙 방식·노림수는 오른쪽 아래
- 타자: 공이 홈플레이트에 닿는 순간 탭해서 스윙(맞히면 아주 잠깐 화면이 멈추는 히트 스톱, 스윙마다 화면 아래 타이밍 미터). 설정 '정밀 타격'을 켜면 공이 있는 곳을 탭해야 맞고 위를 탭하면 땅볼·아래를 탭하면 뜬공, 탭한 자리는 흰 X로 표시. 도루·번트 버튼, 안타 뒤 탭하면 한 베이스 더, 태그업
- 투수: 구종 선택 → 화면을 드래그해 조준 → 손 떼면 투구, 투구 세기 막대, 견제·고의사구. 조준하는 동안 흰 링(목표)과 줄었다 커졌다 하는 노란 링이 보이고, 두 링이 겹칠 때 손을 떼면 '완벽한 릴리스'(거의 노린 곳 그대로), 많이 어긋나면 '실투'(크게 빗나가거나 가운데로 몰림). 존 테두리를 노리면 흰 링이 주황색이 되고 맞는 구간이 좁아지며, 체력이 낮거나 세기가 셀수록 링이 빨라진다
- 수비: 아슬아슬한 타구가 오면 떨어질 곳에 흰 링과 줄어드는 노란 링이 뜨고 시간이 느려짐. 겹칠 때 링을 탭하면 다이빙 캐치(담장 근처는 점프 캐치·홈런 훔치기). 화면 스와이프 다이빙도 됨
- 송구: 주자가 있는 땅볼을 잡으면 베이스 위에 1루·2루·3루·홈 버튼(2루를 고르면 2루→1루 병살 시도), 컴퓨터 주자가 태그업하면 홈/3루 버튼. 1.2초 안에 안 고르면 자동
- 시즌 페넌트레이스(9경기), 홈런더비(10구), 기록실·명예의 전당
- 슬로모션 리플레이, 바람, 낮/저녁/밤, 전광판
- 오른쪽 위 ❚❚ 버튼으로 일시정지(이어하기 / 처음으로). 다른 앱으로 가면 자동으로 일시정지

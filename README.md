# fullcount → 나이트 베이스볼 3D

iPad Safari에서 터치로 치고 던지는 3D 야구 게임. 혼자 만들고 혼자 플레이하는 개인 프로젝트다.

2026-10-31부터 이 저장소의 게임은 **나이트 베이스볼 3D**로 바뀌었다. 예전 풀카운트(Babylon.js, 파일 여러 개)는 git 기록의 커밋 `a6df590`(PR #16 머지)에 그대로 남아 있다.

- `index.html`: 게임 전체가 들어 있는 한 파일. three.js r128을 cdnjs에서 불러온다. 빌드 도구 없이 브라우저로 바로 열면 된다.
- `prompts/night-baseball-update-prompts.md`: 이 게임을 업그레이드하는 단계별 프롬프트(9단계). 코드 작업에 하나씩 붙여 넣는다.

## 게임 내용

- 9회 정식 경기: 초에는 타자, 말에는 투수 시점으로 번갈아 플레이
- 타자: 공이 홈플레이트에 닿는 순간 탭해서 스윙, 도루·번트 버튼, 안타 뒤 탭하면 한 베이스 더, 태그업
- 투수: 구종 선택 → 화면을 드래그해 조준 → 손 떼면 투구, 투구 세기 막대, 견제·고의사구
- 수비: 다이빙 캐치(버튼 또는 스와이프), 홈런 훔치기
- 시즌 페넌트레이스(9경기), 홈런더비(10구), 기록실·명예의 전당
- 슬로모션 리플레이, 바람, 낮/저녁/밤, 전광판

## iPad에서 열기

저장소 Settings → Pages에서 Source를 `main` 브랜치 `/ (root)`로 정하면 `https://myongg14.github.io/fullcount/` 주소로 열 수 있다.

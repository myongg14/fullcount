# fullcount → 나이트 베이스볼 3D

iPad Safari에서 터치로 치고 던지는 3D 야구 게임. 혼자 만들고 혼자 플레이하는 개인 프로젝트다.

2026-10-31부터 이 저장소의 게임은 **나이트 베이스볼 3D**로 바뀌었다. 예전 풀카운트(Babylon.js)는 git 기록의 커밋 `a6df590`(PR #16 머지)에 그대로 남아 있다.

## iPad에서 열기

저장소 Settings → Pages에서 Source를 `main` 브랜치 `/ (root)`로 정하면 `https://myongg14.github.io/fullcount/` 주소로 열 수 있다. 빌드 도구는 없다. 파일을 고치고 올리면 그대로 반영된다.

## 파일 구성

`index.html`이 화면 틀(버튼, 점수판, 타이틀·종료 화면)을 담고, 모양은 `css/style.css`, 동작은 `js/` 폴더의 파일들이 맡는다. 3D 그리기는 three.js r128(cdnjs)을 쓴다.

자바스크립트 파일은 `index.html` 맨 아래에서 **아래 순서대로** 불러온다. 파일끼리 변수와 함수를 함께 쓰므로, 시작할 때 바로 실행되는 코드가 있는 파일은 순서를 바꾸면 안 된다. 경기 화면은 `main.js`가 마지막에 첫 프레임을 시작하면서 움직이기 시작한다.

| 순서 | 파일 | 맡는 일 |
| --- | --- | --- |
| 1 | `js/core.js` | 경기 확률 설정표(`CFG`), 스트라이크존 크기, 공통 작은 함수(무작위 수, 범위 자르기, 부드러운 보간), 트윈(시간에 따라 값 바꾸기) |
| 2 | `js/scene.js` | 렌더러·카메라·조명·그림자, 공통 텍스처/도형 함수, 공과 그림자, 불꽃 파티클, 시간대(낮·저녁·밤·노을) 하늘과 조명, 재질 업그레이드 |
| 3 | `js/stadium.js` | 그라운드·베이스·라인, 담장·관중석·조명탑, 하늘·산·구름·건물, 광고판, 관중(들썩임), 외야 전광판 |
| 4 | `js/players.js` | 관절이 있는 선수 모델, 자세(차렷·달리기·준비), 팔 IK, 투수·타자·포수·심판·수비수·주자, 투구폼·스윙 애니메이션, 유니폼, 벤치 클리어링 |
| 5 | `js/audio.js` | Web Audio로 만드는 관중 소리·함성·신호음·타격음·응원 오르간(소리 파일 없음) |
| 6 | `js/teams.js` | 내 팀·상대 팀 타순과 능력치, 팀 이름·유니폼 색, 시즌 상대 팀, 타자별 핫/콜드 존 |
| 7 | `js/pitching.js` | 투수 데이터와 구종, 공 궤적, 컴퓨터 투수 체력, 투수 시점 조준·세기 막대, 견제·보크, 컴퓨터 타자 스윙, 투수 교체 |
| 8 | `js/batting.js` | 스윙 판정과 타구 결과, 담장 거리, 핫존 보너스, 좌타/우타, 타구 처리 결과 반영 |
| 9 | `js/fielding.js` | 땅볼·뜬공 판단, 수비수 달리기, 타구 비행과 포구, 송구, 다이빙 캐치·홈런 훔치기 |
| 10 | `js/running.js` | 주자 위치, 볼넷 밀어내기, 도루, 태그업, 한 베이스 더, 안타 뒤 주자 연출, 홈런 베이스 돌기 |
| 11 | `js/game.js` | 경기 상태 값(단계, 이닝, 카운트, 주자, 점수), 경기 시작, 다음 투구, 카운트·아웃·이닝, 안타 결과 반영, 시프트·바람, 경기 종료 |
| 12 | `js/season.js` | 시즌 페넌트레이스(9경기), 홈런더비(10구), 시즌 기록, 기록실·명예의 전당 |
| 13 | `js/ui.js` | 점수판·배너, 홈런 리플레이, 상황별 버튼, 투수 선택 버튼, 타자 카드, 미니 존·3D 핫존·스트라이크존 표시 |
| 14 | `js/main.js` | 카메라 위치, 화면 탭 처리, 매 프레임 경기 진행(`update`)과 그리기(`frame`), 시작할 때 한 번 하는 일 |

그 밖의 파일:

- `css/style.css`: 화면 글자·버튼·창 모양
- `prompts/night-baseball-update-prompts.md`: 이 게임을 업그레이드하는 단계별 프롬프트(10단계). 코드 작업에 하나씩 붙여 넣는다.

### 자주 보는 이름

| 이름 | 뜻 |
| --- | --- |
| `phase` | 지금 단계: `title`(타이틀), `windup`(와인드업), `pitch`(공이 날아옴), `hit`(타구), `wait`(다음 투구 대기), `aim`(투수 조준), `anim`(견제 등 연출), `over`(경기 끝) |
| `pitcherMode` | 지금 내가 투수(수비)인지. 정식 경기는 초에 타자, 말에 투수 |
| `balls`, `strikes`, `outs` | 볼·스트라이크·아웃 수 |
| `bases` | 주자 `[1루, 2루, 3루]`. 0이면 비어 있고, 숫자는 그 주자의 타순+1 |
| `pitch`, `swing`, `hit` | 지금 투구·스윙·타구 정보 |
| `now` | 게임 시계(ms) |
| `CFG` | 경기 확률 설정표(`core.js` 맨 위) |

## 게임 내용

- 9회 정식 경기: 초에는 타자, 말에는 투수 시점으로 번갈아 플레이
- 타자: 공이 홈플레이트에 닿는 순간 탭해서 스윙, 도루·번트 버튼, 안타 뒤 탭하면 한 베이스 더, 태그업
- 투수: 구종 선택 → 화면을 드래그해 조준 → 손 떼면 투구, 투구 세기 막대, 견제·고의사구
- 수비: 다이빙 캐치(버튼 또는 스와이프), 홈런 훔치기
- 시즌 페넌트레이스(9경기), 홈런더비(10구), 기록실·명예의 전당
- 슬로모션 리플레이, 바람, 낮/저녁/밤, 전광판
